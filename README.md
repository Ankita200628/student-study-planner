# 🤖 AI Resume Analyzer

An AI-powered web application that analyzes a resume against a job description and helps identify matching and missing skills.

## ✨ Features

- 📄 Upload resume in PDF format
- 💼 Analyze resume against a job description
- 📊 Calculate resume match score
- ✅ Detect skills found in the resume
- ⚠️ Identify missing skills
- 💡 Provide personalized improvement suggestions
- 🎯 Visual match-score progress bar
- 🌐 Clean and responsive web interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- PDFMiner
- Natural Language Processing (NLP)
